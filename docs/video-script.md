# 《一场校区抽奖》— 系统介绍片 制作说明

> 成片：90 秒 / 30fps / 纯代码生成（Remotion + three.js + WebGL 后期），无实拍、无剪辑软件。
> 本文记录**已交付版本**的旁白、分镜与制作方法，与成片逐帧对应。

## 四、广告机那 25 秒（S08–S11）怎么做的

这一段是全片重点，也是唯一用三维的地方：

1. **场景**：明亮校区大厅 —— 暖白墙面（带窗侧渐变与斑驳）、浅色水磨石地面（程序化云斑 + 石子 + 粗糙度贴图）、窗光 + 顶部筒灯、一块深红品牌背板、前台台面与少量道具（全部虚焦）
2. **主体**：1080×1920 竖屏广告机，12mm 圆角边框 + 金色细边，屏幕用真实页面截图（2× 重采样）做 emessive 贴图，叠加一层固定的玻璃反光
3. **屏幕内容**：宣传页 → 等待开奖 → **真实滚动帧 7 张循环**（每张停 3 帧）→ 中奖页（带奖品图 + 「下一位」按钮）
4. **运镜**：暗中推入 → 3/4 侧环绕 → 揭晓时轻微回拉；景深焦平面始终锁在屏幕平面
5. **后期**：Bloom（阈值 1.12，只让屏幕高光与金饰发光）、景深、胶片颗粒 0.03、暗角 0.12，无平面渐变转场

> 亮场景下的关键取舍：环境曝光压到墙面 67% 灰、屏幕自发光 1.45，保证屏幕是画面最亮的东西；背景重度虚化（15–25px）让画面从"3D 效果图"变回"实拍感"。

## 五、制作方式（纯代码）

| 环节 | 用什么 |
| --- | --- |
| 时间轴 / 排版 | Remotion（React），场景即组件，`<Sequence>` 拼帧 |
| 三维 | three.js + @react-three/fiber + drei |
| 后期 | @react-three/postprocessing（Bloom / DOF / Vignette）+ 手写颗粒层 |
| 截图素材 | 本项目实例 + 演示数据，无头浏览器 2× 截图 |
| 旁白 | edge-tts（Azure 神经音色），逐句合成、按实测时长对齐 |
| 音效 | 代码合成（whoosh / tick / shutter / 键盘），拾音效取自 `public/sounds/` |
| 底噪 | 程序生成 -30dB 房间底噪 |
| 音乐 | **不使用**（避免版权问题） |

### 渲染

```bash
# 横屏 1080p（交付版）
npx remotion render AurumFull out/full-1080p.mp4 --codec=h264 --crf=18

# 竖屏 1080×1920
npx remotion render AurumVertical out/vertical-1080p.mp4 --codec=h264 --crf=18

# 4K 母版（ProRes 4444，给调色/剪辑）
npx remotion render AurumFull4K out/master-4k.mov --codec=prores --prores-profile=4444
```

实测：1080p 全片约 2 分钟；4K ProRes 约 8 分钟（concurrency 3）。
